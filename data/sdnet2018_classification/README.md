# SDNET2018 — Concrete Surface Defect Classification

## Overview

This workstream evaluates image-classification models on SDNET2018 for concrete surface defect classification. The reported dataset contains **56,092 images** with binary labels (`0` and `1`) across surface categories **D / P / W**.

Five model architectures were compared:

- ResNet50
- DenseNet121
- EfficientNet-B0
- MobileNetV3-Large
- ConvNeXt-Tiny

Five-fold split CSVs were prepared for the workflow. The comparison table below reports the supplied test metrics at threshold **0.50**.

## Model comparison

| Model | Accuracy | Precision | Recall | F1 | ROC-AUC | PR-AUC |
|---|---:|---:|---:|---:|---:|---:|
| ConvNeXt-Tiny | 87.31% | 57.23% | 89.72% | 69.88% | **95.34%** | **88.58%** |
| DenseNet121 | 87.62% | 58.00% | 89.00% | 70.23% | 95.22% | 88.42% |
| EfficientNet-B0 | 89.42% | 63.11% | 85.44% | 72.60% | 94.65% | 87.67% |
| MobileNetV3-Large | **90.05%** | **65.28%** | 84.00% | **73.47%** | 94.20% | 86.74% |
| ResNet50 | 87.14% | 57.78% | 80.28% | 67.19% | 91.23% | 80.53% |

## Key observations

- **MobileNetV3-Large** achieved the highest accuracy (**90.05%**) and F1 score (**73.47%**) in the supplied comparison.
- **ConvNeXt-Tiny** achieved the highest ROC-AUC (**95.34%**) and PR-AUC (**88.58%**).
- The results show a trade-off among accuracy, recall, F1, and ranking metrics; model selection should depend on the intended evaluation priority.

## ConvNeXt-Tiny threshold details

The supplied ConvNeXt-Tiny `metrics.json` also reports threshold-dependent test results:

| Threshold setting | Accuracy | Precision | Recall | F1 |
|---|---:|---:|---:|---:|
| Fixed threshold 0.50 | 87.31% | 57.23% | 89.72% | 69.88% |
| Validation-derived F1 threshold (~0.89912) | 94.19% | 86.01% | 77.17% | 81.35% |
| Validation-derived recall-90 threshold (~0.50581) | 87.46% | 57.56% | 89.67% | 70.11% |

These threshold-derived figures are specific to the supplied ConvNeXt-Tiny evaluation and should not be interpreted as the fixed-threshold model comparison table.
